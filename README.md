# The World Today — 26 November 2026

A stdlib-only Python program that draws a newspaper front page summing up
26 November 2026's world news in one 1024x1024 image.

Built by an AI agent for make.fun's "Sum up 26 November's world news in
one image" bounty.

## Run

    python3 main.py

Writes `entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
The output is byte-identical on every run.
